VOID JUMP — GitHub Pages files

1. Put this folder alongside MyGame:
   first game/
     MyGame/
     VOID_JUMP_Website/
       support.html
       privacy.html
       style.css

2. IMPORTANT: Replace every REPLACE_WITH_YOUR_SUPPORT_EMAIL in both HTML files with your actual support email.

3. Review privacy.html against the app's actual data collection, advertising consent, ATT settings and App Store privacy disclosures before publishing. This is a starting draft, not a verified legal statement.

4. Upload the three website files to a public GitHub repository. In GitHub Settings > Pages, choose Deploy from a branch, main, /(root).

5. When published, URLs will typically be:
   https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/support.html
   https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/privacy.html

6. Open both pages in a private browser window and confirm they work before adding the support URL in App Store Connect.
